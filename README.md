Step 1: Create GitHub repository
1. Open GitHub.

3. Name: campus-portal
4. Visibility: Public
5. Keep README unchecked.

Step 2: Connect SourceTree to GitHub
1. Open campus-portal in SourceTree.
2. Go to Repository → Repository Settings.
3. Click Add under Remotes.
4. Remote name: origin.
5. Paste your GitHub repository URL.
6. Click OK.
7. 
Step 3: Push branches
1. Click Push in SourceTree.
2. Select remote origin.
3. Tick master and feature/login-page.
4. Click Push.
Step 4: Create Issue
1. Open GitHub repository.

3. Title: Implement Login Page Validation.
4. Add a description.
5. Click Create issue.

2. Base: master.
